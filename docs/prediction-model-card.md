# P4 模型卡与评分口径

## 适用范围

模型只支持 DataCo 公开零售历史验证。下单时输出公开运输延误标签的概率，不预测供应商停产、制造订单断料或真实经营损失。制造场景不能调用此模型；API 对其他 domain 返回 422。

企业页提供固定历史审阅样例，用实际训练模型重新计算概率。样例的输入特征是该次实验冻结的下单时快照；没有客户数据输入界面、实时数据流或制造字段映射。样例实际标签只用于事后人工核对。训练未见类别采用训练编码器的忽略策略，并明确返回告警。

## 固定实验预算

- CPU、2 线程、仅前两个允许核、nice 10、地址空间上限 4 GiB。无 GPU。没有共享环境变更或其他项目依赖。
- 三个概率基线：全局训练延误率、成熟历史产品率（10 个样本平滑）、固定规则 `clip(0.25+0.15*(4-最短计划天数),0.05,0.95)`；另设按重算订单金额排序的业务基线，后者不是概率。
- LogisticRegression：C=0.1/1、liblinear、最多 500 次迭代，共 2 次拟合。
- LightGBM：CPU、120 棵树、learning_rate=0.05、num_leaves=15/31、min_child_samples=40、确定性与固定种子；基础、+历史、+历史+结构图三组各 2 次拟合。
- 共 8 次训练拟合，不在测试集上调参。每组独立训练预处理器：数值中位数/标准化、类别 OneHot（训练低频门槛10、未知忽略），全部只在训练集拟合。
- 全部概率候选（包括基线）按验证 AP 选主模型。阈值只在验证集的 0.05…0.95 固定网格中选最高 F1；同分先选低阈值。不在测试集重新拟合、调阈值或校准。
- 全局初始历史先验 Beta(1,1)，后续仅成熟训练订单贡献。验证与测试使用同一训练截止快照，未加入任何验证/测试标签。

首轮选中 `lightgbm_graph_31`，验证 AP 0.852491；测试 AP 0.858029。基础 LightGBM 的测试 AP 约 0.859，**图结构没有表现出增益**。保留验证选择结果，不按测试最优重新选模型。模型与结构选择不能说明供应链传播存在因果预测能力。前10%名额下，模型延误金额覆盖22.40%，低于金额排序的29.74%；不能把AP提升说成金额保护或收益提升。冻结30%阈值会标记12,620笔且有5,140笔误报，仅作评估，不直接作为生产告警策略。

## 指标

| 指标 | 定义/解释 |
|---|---|
| AP | sklearn `average_precision_score`：按召回增量加权的精确率；不叫梯形积分 PR 曲线面积 |
| Recall/Precision @前5/10/20% | 同一测试集，以 ceil(N×比例) 固定跟进名额。按分数降序、同分按下单时间与脱敏标识固定序；报告人数与样本量 |
| 延误金额覆盖 | TopK 中真实延误订单的重算金额 / 全部真实延误订单金额；非实际损失、节省或 ROI |
| Precision/Recall/F1、混淆矩阵 | 冻结验证阈值下的分类表现，不与 TopK 混淆 |
| Brier/ECE | 概率平方误差、10 个等宽概率箱的加权绝对校准误差，越低越好。金额排序没有概率，不计算 |
| 分组 | 运输服务/市场/月，分别报告样本数、标签占比、AP、ECE 等；单类群体 AP 为 NA，而不是满分 |
| 95% 区间 | 32 个测试日历周为块，固定种子重采样 200 次；对 AP、Recall@10%、Brier 及相对金额/固定规则/基础 LightGBM 的成对 AP 差值提供百分位区间 |

图表 `precision-recall.png/svg` 与 `calibration.png/svg` 使用 Matplotlib 生成，完整报告与原始逐模型概率另存 JSON。样例和错误例按固定等距时间点及最早误报/漏报选取，避免只选成功案例。模型特征可用性是假设；高分也不能排除公开数据生成机制、时间分布与选择偏差。

## 推理、复现与回退

- `/api/v1/prediction/report`、`/cases`、`POST /predict`：两类成员可用，绑定当前 tenant 上下文，数据明确为共享公开基准；不含企业私有记录。只允许服务端已脱敏历史 case，不接受模型路径或任意 pickle。
- 推理返回概率、验证阈值、模型版本、适用域、特征依据、未知类别与实际标签审阅值。模型仅从本地训练产物的固定目录加载，核对清单与文件 SHA256 后加载；不对外下载模型。
- `/prediction/artifacts/{name}` 只允许固定公开报告/图表/审计清单，不开放任意文件。无实验返回503，不伪造0概率。
- `.local/prediction/experiments/` 每次创建独立不可覆盖目录；训练失败也保留。`active.json` 原子指向完整实验。训练过程不重建数据库、图谱或向量。
- `make phase4-reproduce` 新建一轮固定实验，逐字节核对协议、源文件清单、订单切分、选型、阈值、运行配置及所有模型测试概率，不切换当前模型。耗时/RSS不要求一致。
- 回退可恢复一个经 `phase4-audit` 验证的旧 active 指针，或停止提供预测验证。若需要切换历史率基线，应新建显式部署配置/实验版本并标明基线，不手改模型报告或删除失败记录。
- 数值与绘图库完整锁：`requirements/phase4-runtime-lock.txt`；原专属环境的增量安装清单：`requirements/phase4-ml.txt`。禁止用锁文件强制升级其他共享环境。

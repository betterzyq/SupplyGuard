## 手算与成本结果

固定手算样例：初始库存 100、日需求 20、日到货 20、BOM 1:1，单订单 200 件，D10 承诺，14 天窗口。

| 条件 / 方案 | 首次缺料 | 峰值缺口 | 完成 | 延期订单金额 | 增量成本 |
|---|---|---:|---|---:|---:|
| 停供 3 天 | 无 | 0 | D10 | ¥0 | ¥0 |
| 停供 7 天 | D6 | 40 | D12 | ¥1,280,000 | ¥0 |
| 停供 7 天 + 替代 20/日、7 天、提前期 1 天 | 无 | 0 | D10 | ¥0 | ¥4,500 |
| 停供 7 天 + 调拨 80、提前期 1 天 | 无 | 0 | D10 | ¥0 | ¥1,140 |
| 上述替代与调拨组合 | 无 | 0 | D10 | ¥0 | ¥5,640 |

D1/D2/D3 结余 80/60/40；七天停供时 D6 缺口 20、D7 缺口 40。费用分别为 `20×7×25+1000` 与 `80×8+500`。增加初始库存到 200 在本例消除缺料；需求 0% 无延期，缓冲为 null。

制造案例中，MAT-01 的在途改道只重排原 80 件批次，合计仍到货 80 件，增量成本 ¥2,800；在途加急的原路径仍受港口限制，费用 ¥2,000，未伪造交付改善。此案例用于说明措施成本、约束和有效性必须分别检查。

## 隔离与限制

只操作 SupplyGuard 代码、专属环境和自有验收进程。没有读取、修改、启停两个受保护的 risk_vlm 项目，没有全局软件安装、基础环境/驱动/CUDA 修改、全局进程清理或原 3000/8000 启停。本阶段未安装新的前后端依赖，未执行数据库迁移、旧 seed、图谱或向量重建；登录与验收账号准备沿用原有幂等入口。

仿真假设包括共享库存池、日初到货、按承诺日排序、生产完成即交付可用、分物料能力与有限备援库存，不是生产调度最优解，也未模拟换线、跨厂物流、小时级过程或真实采购执行。结果是确定性点估计；窗口外未完成订单待判断，窗口内未完成只给延误下界。方法、口径与接口见 [仿真方法说明](../simulation-method.md)。

快照是本机按个人保存的计算证据，不等于 P5 的企业任务、正式报告或数据库业务持久化。正式数据接入与公开数据预测精度仍属后续阶段。

# P4 实测报告：预测与可信评测

日期：2026-10-17（北京时间）。用户已验收 P3 并授权 P4。本报告记录开发自测，P4 已获用户人工验收通过；当前开始 P5。

## 交付结果

新增企业“预测验证”页 `/prediction`，将公开历史订单预测与制造业地图/影响模拟明确区分。提供实际模型的历史样例推理、基线比较、图特征消融、校准/分组/区间、错误样例、科学图表与可下载证据。管理员 `/benchmarks` 改为新版契约审计与已废弃的历史记录，避免继续用旧岗位金标准报告新策略效果。

公开数据使用有署名许可的 DataCo v5，来源/官方文件哈希固定；Olist 因候选许可有非商业限制未作为主数据。没有引入 GNN、GPU、付费评测裁判或其他项目模型。完整来源与队列局限见[数据卡](../prediction-data-card.md)，固定预算与接口见[模型卡](../prediction-model-card.md)。

## 真实实验与结果

当前模型版本：`20261017T074845493997:lightgbm_graph_31`。独立复现版本：`20261017T075052001180`。协议 `dataco-order-time-v1`，随机种子20261017。

- 180,519 个订单行 / 65,752 单，排除取消/疑似欺诈2,855单；这两类解释全部4,423行标签差异。无额外异常订单，安全读取字段无缺失、行ID无重复、坐标越界0；客户坐标不作供应商特征。
- 订单粒度按时间切分，训练39,386 / 验证9,306 / 锁定测试13,071，交集0；1,134笔资格订单因边界观察期不足排除。测试延误占比57.56%。标签成熟是明确披露的+7天代理，缺少实际入库/签收日志。
- 固定8次拟合：LR两组C、LightGBM三个特征组各两个叶数。所有预处理只拟合训练集；历史标签在预测时点前成熟，验证/测试冻结训练历史。验证集选模型与30%阈值，未用测试指标修改参数/阈值/切分。
- 主模型验证 AP 0.852491，测试 AP 0.858029，95%周分块区间[0.849252,0.868560]；AP是average precision，不是分类准确率或梯形积分PR面积。

完整JSON还包含其他C/叶数、前5/20%、ROC-AUC、各分组、混淆矩阵、校准箱与10个错误例。

**不能把本次AP提升说成经营收益提升。** 主模型捕获更多延误订单，但同样名额的延误金额覆盖低于金额排序。金额保护与订单数量目标需要分别选择策略，没有计算真实损失、节省或ROI。

**没有证据支持图特征增益。** 验证集选中了图模型，但测试AP略低于基础模型；相对验证选出的基础LightGBM31，成对AP差值95%区间[-0.002544,0.000100]包含0。保留原验证选择，不按测试最优换模型。这里的图是产品/类别/市场历史共现结构，不是制造供应链因果图。

**F1阈值不适合直接变成生产告警。** 30%冻结阈值下Recall99.42%、Precision59.27%，TP7,480 / FP5,140 / TN407 / FN44，共标记12,620笔；界面明确提示误报工作量。概率ECE0.028689、Brier0.174953，不代表可直接迁移或上线。

训练本轮120.691秒，峰值RSS468.87 MiB；双CPU线程、前两个允许核、nice10、地址空间上限4GiB、未使用GPU。独立复现182.311秒，因同时有前端构建更慢；8个关键产物逐字节一致，包含全部候选测试概率。耗时/RSS不要求相同，也不是服务器SLA。

## 旧评测修订

- 完整有向带类型路径匹配、精确引用precision/recall、重复证据不重复得分、无金标准返回NA/有效分母。
- allow / denied / no_evidence / error区分；不再用预期拒绝决定输出，不用“未找到证据”冒充拒绝。旧岗位敏感词黑名单移除，评测用户查询补tenant限制。
- 记忆种子/回答出现“历史记忆”不再自动算命中；完整订单号实体可提取。
- `enterprise-v2.json`：8题校正图金标准、17项离线权限/评分契约；`graph-enterprise-v2.jsonl`：8题可直接加载的图评测问题；`rag-enterprise-v2.jsonl`：9题具体文本证据标注。当前租户块不能精确解析证据时明确失败，不能整份文档所有块算金标准。
- 旧数据和数据库记录保留，旧Web执行入口409；本阶段未运行在线检索或记忆质量实验，不报告对应准确率。17个契约通过不是RAG准确率。详见[评分修订](../evaluation-v2.md)。

## 人工验收入口

按[人工验收第4阶段](../manual-acceptance.md)执行P4-H1—P4-H12。当前专用验收服务在127.0.0.1:8100 /3100运行，电脑沿用已有SSH转发。企业进入“预测验证”，管理员另看“基准评测”。需要亲自复训可运行 `make phase4-reproduce`，无需先训练或下载。

本阶段只操作本项目及既有SupplyGuard专属环境；没有数据库破坏性seed、图谱/向量重建、全局环境/CUDA/代理修改或GPU使用。停止/更新服务只使用本项目启动器核验过的PID、启动时间和进程组。保留全部已有未提交修改，没有执行提交、重置或合并。

P4通过后才进入P5：处置闭环与企业数据接入。当前没有制造业预测迁移验证、实时接入、在线业务收益或生产告警策略。

# P5 实测报告：处置闭环、导入与企业API

日期：2026-10-17（北京时间）。P4已获用户人工验收通过，本阶段已授权开展；P5已获用户人工验收通过，现已授权进入P6。

## 交付

新增“处置与复盘”`/actions`和“企业数据”`/workspace`，企业用户与管理员共享本企业业务。风险研判/控制塔可转任务，P3本人模拟与P4历史预测可主动归档为企业副本，再建立处置依据。原P3个人文件不自动共享，P4固定模型与数据不修改。

- 企业持久化：站点、订单、批次、风险事件使用类型校验的实体表与同租户复合引用；预测/模拟采用受控版本归档。另有任务、批次、报告、幂等、审计与本地事件/订阅，共9张新增表。旧业务表结构不改。
- 状态闭环：待认领→处理中→待验证→完成，支持有理由退回/取消；记录责任人、期限、措施、人工费用、验证依据、前后状态和版本。关闭后只读；完成任务不会自动标订单已交付、解除所有风险或执行采购。
- 数据接入：UTF-8 CSV/单表XLSX模板、中文字段映射、预检/前10行、错误行、原子确认。重复不重复计数，已有编号不同内容拒绝覆盖；引用限定同企业。
- 真实导出：风险/公开评测XLSX与CSV，固定字节+SHA256、鉴权下载、24小时有效期。旧MCP导出从stub改为真实ready下载。报告列表不加载文件正文。
- 企业API：经认证可下载OpenAPI，字段/模板、分页/过滤、幂等键、稳定业务错误码、版本冲突；本地事件与业务同事务保存，可游标重放，没有外发消息或真实采购。

完整契约见[企业工作区与API](../workspace-api.md)；样例位于`data/examples/phase5/`，API客户端例子`scripts/workspace_api_example.py`默认只做模拟预检。

- 企业上传仅新增模式，不自动覆盖原记录，不宣称实时ERP/承运商接入；P2地图仍是明确标注的模拟场景。上传数据可通过工作区任务、报告与API使用。

- 事件订阅目前仅本地轮询与游标重放，没有外部Webhook、邮件/消息投递。大规模队列、全量实时集成及生产SLA未验证。

- 工作范围仅SupplyGuard及既有专属环境；没有其他项目代码/模型/环境操作，没有GPU、全局安装、CUDA/代理修改、图谱或向量重建。没有提交或丢弃原未提交工作。

- 本地底图、字体、Worker 与授权清单；支持联网准备后断网刷新核心地图/物流页。WebGL 失败提供可操作列表。离线仅允许合成演示，恢复网络重新验证账号；API/认证响应不进入公共缓存，退出清除合成快照。

## 性能记录及解释

环境：Linux x86_64 / Intel Xeon Gold 6459C；构建、浏览器限制前两可用 CPU 核及低调度优先级；Node.js 22.21.1，Playwright 1.58.2 / Chromium 145。使用 SwiftShader 软件 WebGL，**没有使用服务器 GPU**。

| 测量 | 本次结果 | 范围 |
|---|---:|---|
| 默认业务页首图 ready | 1,832 ms | 从登录后的风险控制塔页内导航至数据、字体和地图初始化；随后另做实际画面断言 |
| 规模 | 1,000 站点 / 2,000 路线 | 确定性合成几何负载，不代表真实企业订单规模 |
| 镜头移动 | 17 次 render / 2,653 ms，约 6.4 次/秒 | 1920×1080 视口；约 2200 ms 镜头动画，含实际延迟；绘制可交互但低帧率 |
| 页面 JS heap | 40,978,628 bytes，约 39.1 MiB | CDP JSHeapUsedSize；不含浏览器总 RSS、全部 Worker 或显存 |
| network API P50 / P95 | 6.99 / 8.82 ms | 20 次串行热请求，经本机 3100 代理及实际认证；非并发吞吐或 SLA |

软件 WebGL 的规模负载尚不够流畅，不能据此宣传 60 FPS；用户电脑硬件加速下的表现需要人工实测。当前默认业务数据只有 9 个可见关联站点、8 个批次，规模入口单独供管理员使用。最终性能上限和进一步优化在 P6 依据目标设备复测；本阶段不宣称未测规模。

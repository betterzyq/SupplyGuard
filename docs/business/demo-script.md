# 约5分钟竞赛演示脚本

前置：`make acceptance-up`；从电脑通过Remote-SSH转发3100；enterprise登录，进入“演示导览”。完整三个故事的操作验收另用10–15分钟，此脚本为5分钟介绍节奏，不代表全链路操作必然只需5分钟。所有制造故事为模拟。

| 时间 | 操作 | 讲述与核验 |
|---|---|---|
| 0:00–0:35 | 商业价值 | 面向电子/装备制造的采购、计划、物流。问题是决定先保护哪些交付，而非再增加一组风险分数。无真实客户/收入背书 |
| 0:35–1:35 | 导览选港口拥堵→定位风险站点→返回地点列表→关联订单 | 港口、物料、订单放在同一网络。显示敞口按唯一订单求和，不称损失。回放不能露出未来轨迹 |
| 1:35–2:35 | 影响与方案，运行默认模拟 | 库存能缓冲风险；对照基线、方案A/B、增量成本、缺料时间，结果是规则仿真。输入改变后必须重算 |
| 2:35–3:15 | 导览切二级供应商停产，再定位；切区域灾害 | 展示间接依赖与区域共同暴露；每个故事都有独立定位、仿真、任务入口；重置仅恢复视图，不删审计 |
| 3:15–4:10 | 港口故事→建立场景任务→显式保存模拟事件→指定本人与期限、措施→开始、提交、验证完成；企业数据生成风险报告 | 责任、期限、费用、复盘结果持久化；完成任务不自动变成订单交付。报告是实文件且有来源与哈希。提前准备一条未完成演示任务以控制讲述时间 |
| 4:10–4:40 | 预测验证→基线与金额捕获 | 公开零售历史模型独立验证，制造业迁移未验证；图增强尚未优于基础模型；不将仿真当预测精度 |
| 4:40–5:00 | 商业价值→投入产出假设与六周试点 | 可编辑假设，负回报照常显示。收费是提案，真实效益留给企业影子试点测量 |

演示前检查：登录两类账号；地图加载完成；已下载模型审计通过；准备本人的任务和报告；不要公开显示token、终端.env或真实企业文件。无需外部AI/地图请求；外网不可用而本地服务可用时仍可运行核心链路。

意外处置：WebGL失败使用`/supply-chain?fallback=1`列表；浏览器断网仅缓存地图可看，写入不可用；API失败应重试连接，不删除业务数据。当前平台没有服务工作线程，不承诺首次访问完全断网可启动。

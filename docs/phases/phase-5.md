# P5：处置闭环、导入与企业 API

## 需求
OPS-01、ING-01、API-01；前置 P4 人工通过。新增实体持久化，仍只有两类角色。

## 开发
1. 为站点/订单/批次/事件/预测/模拟/任务增加带 tenant 的持久化模型及迁移，保留原始来源与导入批次。
2. 任务状态：待认领→处理中→待验证→已完成/已取消；记录责任人、期限、措施、费用、结果和状态变更审计。
3. CSV/Excel 提供模板、预检、字段映射、错误行明细和确认导入；导入幂等、事务回滚、同租户引用校验。
4. 生成真实可下载风险报告和评测报告；下载鉴权、tenant 检查、失效策略，禁止继续以 stub 当成功。
5. 企业 API 与 OpenAPI 示例、分页/过滤、稳定错误码、幂等键；事件订阅先提供本地可验证能力，外发消息与真实业务执行另行授权。

## 测试与人工操作
上传有效表→预览→确认→重启后核对；导入含错误坐标/重复单号/跨租户引用的表，确认未产生半成品；重复导入不重复计数。创建任务→分配→执行→完成→回放审计；导出后核对金额及来源标识。

迁移先在隔离数据库测升级/降级，备份确认后操作项目库；不重置旧图谱和业务数据。测试并发更新和他租户下载拒绝。

## 交付与回滚
交付迁移说明、数据模板、API 示例、任务审计样例、导出文件及验收命令。数据库回滚按已验证迁移执行，先备份新增业务数据，不用全库重建。人工通过后进入 P6。

## 本次落地约定

四类导入对象采用带类型校验的统一实体表与同租户复合引用，新增模式不覆盖既有记录；归档/任务/报告/事件全部持久化。新增企业工作区与处置复盘页，原个人模拟不会自动共享，演示地图不自动切成未核验上传数据。本地事件只轮询重放，不外发。详见[企业API](../workspace-api.md)、[迁移恢复](../phase5-migrations.md)、[人工验收](../manual-acceptance.md)与[P5报告](../reports/phase-5.md)。

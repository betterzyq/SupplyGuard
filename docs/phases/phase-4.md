# P4：预测与可信评测

## 需求
ML-01、EVAL-01；前置 P3 人工通过。评测协议在训练前固化。

## 开发
1. 下载前确认 DataCo/Olist 许可与获取方式，保存来源、版本、哈希与字段说明；不能获取则记录真实原因和候选替代。
2. 数据审计：订单粒度、取消订单、承诺与实际日期、未成熟标签、异常坐标、缺失/重复；不把客户经纬度当成供应商坐标。
3. 按时序切分并保留锁定测试集；同单不跨集合，历史聚合只用预测时点已知记录，必要时留标签成熟间隔。
4. 比较历史延误率、业务规则、逻辑回归、CatBoost/LightGBM；固定预算，验证集选阈值。图特征单独消融，不强行引入 GNN。
5. PR-AUC、Recall@K、Precision、校准与分组表现；有延误天数任务则 MAE/区间；按金额排序作为业务价值基线。报告置信区间、样本量和失败例。
6. 修复旧金标准、路径匹配、引用 precision/recall、权限拒绝与无证据混淆；两类权限新数据集版本化，旧岗位基准标记废弃。
7. 模型推理返回概率、训练适用范围、版本、特征依据；无法适配制造演示字段时展示独立历史验证页，不伪称迁移有效。

## 测试与人工操作
先审计字段可用时间清单→查看切分日期与订单交集为零→复跑固定实验→核对模型与基线样本一致→抽查泄漏字段禁用→检查失败样例。训练默认 CPU，限制线程/内存；不使用其他项目模型或 GPU。

没有显著优于基线时如实交付结果，分析原因；不通过调测试集强行制造提升。公开数据结果、模拟传播结果、RAG/权限结果分别报告。

## 交付与回滚
交付数据卡、模型卡、实验配置、评测 JSON/图表、复现命令和依赖锁。模型可切回历史率基线；保留测试集和报告，禁止删除失败实验。人工审计通过后进入 P5。

## 本次实现与审阅入口

公开数据选择 DataCo v5（CC BY4.0），固定8次拟合；独立 `/prediction` 页面，制造业迁移未验证。旧评测完成评分器修复、8题图路径与9题具体证据RAG金标准；17项离线契约不等于在线检索准确率。实际命令和结果见 [人工操作](../manual-acceptance.md) 与 [P4报告](../reports/phase-4.md)。

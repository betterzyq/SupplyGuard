# P6：整体交付与商业演示

## 需求
COM-01、NFR-01 及全部已验收需求回归；前置 P5 人工通过。

## 开发与验证
1. 三个可重置业务场景：港口拥堵、二级供应商停产、区域灾害。每个包含发现、地图定位、影响、方案、任务与复盘。
2. 演示模式自足，网络不可用时说明哪些能力离线、哪些需要服务；不伪造真实接入、客户数据或模型结果。
3. 商业材料：目标客群、购买决策人、痛点、竞品差异、订阅/API/部署方案、试点路径和成本。市场及回报数字列来源或假设。
4. 固定设备与数据规模，记录地图首屏、筛选响应、API P50/P95、资源占用和错误率；修复主要瓶颈后再确认容量。
5. 整体权限/租户/个人会话/导出审计回归；检查无密钥进前端、无危险重置命令、专用启动关闭行为正确。
6. 更新 README、运行手册、限制、备份/回滚及已知缺陷，给出约 5 分钟演示脚本和完整验收清单。

## 人工验收
分别用 enterprise/admin 登录，运行三个业务场景；在离线/故障状态验证可解释降级；复跑 P4 实验；导入自己的样例并核对结果；检查所有收益与精度说法的证据。记录最终通过范围和待办，不能用演示成功替代模型审计。

## 交付与回滚
交付版本清单、部署/关闭命令、完整测试与人审记录、商业说明和演示素材。保留上一已验收版本及数据备份；操作仅针对 SupplyGuard。总体完成必须经用户人工确认。

## 实现交付入口

P1—P5已人工通过。本阶段已实现`/showcase`三场景导览与安全视图重置、`/value`商业价值和假设测算、P1—P5整体回归与固定采样、交付清单及P5生产前端/库备份保留。没有数据清空式场景重置、真实ERP/承运商接入或计费托管PaaS承诺。

实际证据、性能与保留项见[本阶段实测报告](../reports/phase-6.md)，可执行人审见[验收手册P6](../manual-acceptance.md)，商业资料见[商业说明](../business/brief.md)，操作与回退见[运行手册](../operations.md)。P6总体验收待用户确认。
